# Instrucciones para Claude

Leé primero `README.md`: tiene el mapa completo del proyecto (dónde está cada cosa, cómo se arma, la base, Mercado Pago, reglas de negocio y pendientes).

- Se edita `src/app.js` / `src/style.html`, después `python3 src/build.py` regenera `index.html`.
- Hablar con el usuario en español, simple y sin tecnicismos.
- Nunca subir datos reales sin cifrar, contraseñas ni tokens.
- Al probar con datos reales, bloquear las escrituras a Supabase.
- Mantener este README al día cuando cambie algo importante.
